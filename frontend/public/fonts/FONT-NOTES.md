# Home Court Pixel

Home Court Pixel is a modified version of Press Start 2P by The Press Start 2P
Project Authors. Its glyph outlines and vertical metrics are stretched by 20%,
with the original horizontal advances preserved. The derivative uses a new
family name and remains licensed under the SIL Open Font License 1.1 in OFL.txt.

Regenerate it with `python scripts/generate-retro-font.py` after installing
`fonttools`. The generated font is bundled; the website build does not require
Python or fonttools.
