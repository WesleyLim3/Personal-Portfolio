# Retro basketball portfolio concept

The React implementation is in `src/App.tsx`, `src/App.css`, and `src/index.css`.
The self-contained, built HTML preview is `output/arcade-preview.html` and can be opened locally in a browser. Browser automation verification was unavailable because starting a local server was not approved and the browser tool does not allow file URLs.

## Player artwork prompt

Use case: stylized-concept. Asset type: original pixel art for the right side of a retro basketball arcade portfolio website. Use the reference photo only for the young East Asian man's identity: thick black hair, friendly face. Reimagine him as a basketball arcade character in a red basketball jersey with cream trim, jersey number 01, holding a basketball at his hip with one arm, confident relaxed standing pose, three-quarter portrait from head to upper thighs. True low-resolution 16-bit pixel art from 1994 Sega Genesis / NBA Jam and NBA Live 95 era, chunky deliberate square pixels, limited color palette, no smooth painted gradients, sharp dither shading, readable expressive face. His figure occupies center two thirds of square composition. Background: deep indigo and cobalt packed basketball arena, electric cyan illuminated scoreboard shapes high above, a purple basketball hoop to upper right, warm golden hardwood court below. Pixel spotlights and tiny pixel crowd. Dramatic warm amber light from left and purple blue rim light. Nostalgic arcade sports character selection art. No logos, no text outside the jersey number, no UI, no border, no watermark. The result must look like an authentic pixel sprite scene, not a modern photo with pixel filter. Square image.
