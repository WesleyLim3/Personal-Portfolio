## Welcome to my Personal Portfolio!

## Built With
- React
- TypeScript
- Vite

## Project Structure

The frontend lives in `frontend/`, including its source code, public assets,
build configuration, scripts, and design previews. The repository root is ready
for a future FastAPI backend alongside it.

## Run the Frontend

```sh
cd frontend
bun install
bun run dev
```

Run `bun run build` to create a production build in `frontend/dist/`, or
`bun run lint` to check the code. Run these commands from `frontend/`.
